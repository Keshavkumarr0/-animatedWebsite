# 🎨 Animated Website - GSAP & React.js

A stunning collection of highly animated websites built with **React.js** and **GSAP** (GreenSock Animation Platform). This project demonstrates advanced animation concepts and smooth, professional web animations.

![Website Preview](https://img.shields.io/badge/Live-Demo-brightgreen?style=for-the-badge)

## 🌐 Live Preview

Check out the live website here: [https://animated-website-two-mocha.vercel.app/](https://animated-website-two-mocha.vercel.app/)

## ✨ Features

- 🚀 **High-Performance Animations** - Smooth 60fps animations using GSAP
- ⚛️ **React.js Framework** - Modern component-based architecture
- 🎭 **Multiple Animation Concepts** - ScrollTrigger, Timelines, Tweens, and more
- 📱 **Responsive Design** - Works seamlessly across all devices
- 🎨 **Beautiful UI/UX** - Professional and engaging user interface
- 🔥 **Production Ready** - Deployed on Vercel

## 🛠️ Technologies Used

- **React.js** - JavaScript library for building user interfaces
- **GSAP (GreenSock)** - Professional-grade animation library
- **Vite** - Next-generation frontend build tool
- **CSS3** - Modern styling and layouts
- **JavaScript (ES6+)** - Latest JavaScript features

## 📚 GSAP Concepts Covered

This project includes clear implementations of:

- **ScrollTrigger** - Scroll-based animations
- **Timeline** - Sequenced animations
- **Tweens** - Simple property animations
- **Easing Functions** - Custom animation curves
- **Stagger Effects** - Delayed animations for multiple elements
- **Pin & Scrub** - Advanced scroll effects
- **MotionPath** - Complex animation paths

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. **Clone the repository**
```bash
git clone https://github.com/Keshavkumarr0/-animatedWebsite.git
cd -animatedWebsite
```

2. **Install dependencies**
```bash
npm install
```

3. **Run the development server**
```bash
npm run dev
```

4. **Open in browser**
```
http://localhost:5173
```

### Build for Production

```bash
npm run build
```
